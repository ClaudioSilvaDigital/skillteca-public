# How Skills Work

## What is a Skill?

A skill is a reusable framework that helps an AI assistant perform a specific task consistently.

Unlike a simple prompt, a skill usually includes:

* Purpose
* Context
* Inputs
* Process
* Expected outputs
* Best practices

## Skill Structure

A typical skill contains:

### Purpose

Defines what the skill is intended to accomplish.

### Inputs

Information required to execute the skill effectively.

Examples:

* Business goals
* Audience information
* Project requirements
* Constraints

### Process

A structured sequence of steps that guides execution.

### Outputs

The expected results generated by the AI assistant.

Examples:

* Plans
* Reports
* Recommendations
* Strategies
* Analysis

## Why Use Skills Instead of Individual Prompts?

Skills offer several advantages:

* Greater consistency
* Better scalability
* Easier reuse
* Improved collaboration
* More predictable results

## Cross-Platform Compatibility

Most skills can be adapted to work with:

* Claude
* ChatGPT
* Gemini
* Open-source LLMs
* Custom AI agents

## Example

A marketing campaign skill may include:

1. Goal definition
2. Audience analysis
3. Channel selection
4. Messaging strategy
5. KPI definition
6. Optimization recommendations

The same skill can be reused across multiple campaigns and AI assistants.
